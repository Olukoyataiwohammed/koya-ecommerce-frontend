# 🛒 Koya E-commerce / Restaurant App (Frontend)

A modern React-based e-commerce/restaurant web application with product browsing, cart system, and support messaging system connected to a Django backend.

---

## 🚀 Features

- 🛍️ Product/Menu listing
- 🔍 Category filtering
- 🛒 Shopping cart system
- 👤 User authentication (if added)
- 💬 Support chat system (user ↔ admin)
- 📩 Message + admin reply system
- 🔄 Live message fetching
- 📱 Responsive UI

---

## 🧑‍💻 Tech Stack

- React.js
- JavaScript (Fetch API)
- CSS
- Django REST API (Backend)
- PostgreSQL / SQLite (Backend DB)
